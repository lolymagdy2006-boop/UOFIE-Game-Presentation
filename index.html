1. Exact Game Idea

UOFIE Game

An interactive educational quiz game for UFE students and professors, inspired by Kahoot. Professors create lecture-based quizzes; students join, earn points, and climb leaderboards.

How the Game Works

👨‍🏫

Professors

  • Create account & log in
  • Build quizzes per course/lecture
  • Add questions, answers & timers
  • Start games & view results
👨‍🎓

Students

  • Log in with university account
  • Join via game code or QR
  • Answer under time pressure
  • Compete on live leaderboards

2. What Makes UOFIE Different?

Unlike generic quiz apps, UOFIE is built specifically for UFE:

  • Organized by university courses & lectures
  • Multi-level leaderboards (Quiz → Course → Class → Department)
  • UFE branding & campus-style competition
  • Professor analytics tied to real courses

15. Development Process

  1. Research & concept - define features & users
  2. UI/UX design - Figma wireframes & mockups
  3. Database design - MySQL schema
  4. Frontend build - HTML/CSS/JS screens
  5. Backend build - PHP APIs & auth
  6. Integration - connect UI to database
  7. Testing - classroom trials & fixes
  8. MVP release - core features first

16. Minimum Viable Product (MVP)

First version includes:

  • Student & professor login
  • Quiz creation (multiple choice)
  • Join via code / QR
  • Timer & automatic scoring
  • Quiz leaderboard
  • MySQL + PHP backend

Later: course/class/department leaderboards, badges, video questions, deeper analytics.

20. Short Conclusion

UOFIE turns classroom quizzes into a competitive, course aware game tailored for UFE.

It combines real time play, multi level leaderboards, and professor tools in one platform.

21. Final Description of the Idea

UOFIE is a web based educational quiz game for The French University in Egypt. Professors create lecture quizzes; students join live, earn points, and climb quiz, course, class, and department leaderboards - making learning more engaging through play and competition.
